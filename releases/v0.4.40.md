## Stacks v0.4.40

### New

- **Resizable interface text** — use **⌥⌘+** and **⌥⌘−** to resize application chrome independently from terminal, Pi, and DIFF content.
- Interface font size is persistent and configurable under **Settings → Interface**.

### Fixes

- **Reliable post-merge worktree removal** — after `/cleanup` settles and workspace processes stop, Stacks now removes the exact registered Git worktree before deleting the workspace entry.
- Cleanup refuses to remove the primary checkout, unregistered directories, or worktrees with modified or untracked files. Failed removal preserves the Stacks workspace for safe recovery.

### Improvements

- The Pi context bar below the composer now follows the interface font-size setting.
- Sidebar, topbar, Developer Services, dialogs, menus, and other interface text resize together while terminal, Pi transcript/composer, and DIFF content retain their dedicated **⌘+** and **⌘−** sizing.

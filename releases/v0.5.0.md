## Stacks v0.5.0

### New

- **Kanban-first workflow** — manage local and Superthread work from a project-aware board spanning refinement, agent work, human review, approval, and completion.
- **Card-native development environments** — create isolated Git branches and worktrees, run persistent Pi agents, inspect changes, and operate project services directly from a card.
- **Integrated delivery workflows** — validate repositories, commit approved work, create and monitor pull requests, merge locally or through GitHub, resolve target-branch conflicts, and safely clean up card environments.
- **Parent and child cards** — synchronize Superthread hierarchies, represent aggregate parent cards, and navigate related work from compact hierarchy badges.
- **Direct Work mode** — continue working directly in a project when a card environment is unnecessary.
- **Board-aware command palette** — search and open cards alongside project actions.

### Improvements

- Card workflows use durable, revision-safe backend state with idempotent transitions and resumable cleanup.
- Repository operations are coordinated by Git identity to prevent conflicting work across cards and worktrees.
- Card agents continue running independently of open views and recover active sessions after relaunch.
- Card detail combines overview, agent chat, terminal, diff, pull-request status, project assignment, and workflow actions.
- Superthread synchronization handles ownership, partial failures, relationship hydration, and managed-list scope explicitly.
- Pi chat supports structured responses, quick YES/NO actions, safe rich-text rendering, and pane-aware file references.

### Fixes

- Prevents stale background updates from changing the currently selected card.
- Preserves approval across target-merge conflict resolution.
- Makes worktree creation and cleanup compensating, resumable, and safe against dirty or unregistered directories.
- Improves card layout bounds, modal layering, pull-request readiness indicators, and board header hierarchy.

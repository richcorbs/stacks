## Stacks v0.4.31

### Improvements

- **Cleaner terminal workspace** — removed the persistent bottom status bar so terminal and Pi GUI content has more vertical space.
- **Git context in DIFF** — the DIFF tab now shows the current branch, diff source, and working-tree status counts in a compact header. Pull-request diffs show their changed-file count.
- **Simpler Git state ownership** — Git context is loaded where it is used instead of being polled and passed through the entire workspace layout.

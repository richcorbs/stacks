## Stacks v1.0.0

Stacks has been rebuilt as a Tauri, React, and Rust application.

### Highlights

- Persistent project, workspace, terminal, and split-pane workflows
- xterm.js terminals backed by native PTY processes
- Integrated Pi GUI sessions with tools, images, skills, and prompt commands
- Built-in Git diff review and GitHub pull request/action panels
- Signed in-app updates from GitHub Releases

This release replaces the previous Zig/AppKit implementation while preserving the Stacks product and GitHub repository.

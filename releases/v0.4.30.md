## Stacks v0.4.30

### New

- **Background activity notifications** — optionally receive native macOS notifications when a background Pi run finishes or a terminal exits. Notifications include the project and workspace name, and Settings includes a direct test action.

### Improvements

- **Pi-first workspace creation** — new workspaces now default their first terminal to Pi GUI while retaining the shell Terminal option.
- **Reliable native delivery** — notifications use the modern macOS notification API, native window-focus detection, and correctly identified ad-hoc signed app bundles for the existing free release process.
- **Expanded project documentation** — the README now documents Stacks' terminal, Pi, developer-service, automation, persistence, development, and release workflows in detail.

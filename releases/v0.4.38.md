## Stacks v0.4.38

### New

- **Per-project notes** — each project now has its own persistent scratch pad for commands, links, reminders, and working notes.
- **Fast notes access** — open or close project notes with **⇧⌘O**, the top-bar notes button, the native Shortcuts menu, or the command palette.

### Improvements

- Project notes cover the main workspace without tearing down terminal or Pi GUI sessions.
- Closing notes restores focus to the active terminal.
- Notes save automatically in the project store and safely default to empty for existing projects.

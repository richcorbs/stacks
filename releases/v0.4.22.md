## Stacks v0.4.22

### Improvements

- **PR-aware diff review** — clean workspaces with an open pull request now show the committed PR diff against its base branch.
- **Workspace PR indicators** — workspace rows show an aligned GitHub-style merge icon when their branch has an open PR; clicking it selects the workspace and opens DIFF.
- **Refined workspace navigation** — reduced left navigation padding while preserving indentation, separators, rounded selection pills, and consistently aligned status indicators.

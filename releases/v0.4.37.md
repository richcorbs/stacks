## Stacks v0.4.37

### New

- **Post-merge workspace cleanup** — the merge confirmation can run `/cleanup` in the workspace associated with the selected PR, stop all workspace processes, and delete the workspace after cleanup succeeds.
- **Safe PR-to-workspace targeting** — cleanup resolves the related workspace within the active project using detected PR information and head-branch matching instead of relying on whichever workspace is focused.
- **Resumable cleanup operations** — Stacks persists each cleanup stage before merging. Interrupted operations can be resumed or cancelled after restart.

### Improvements

- Merge retries safely recognize PRs that GitHub already reports as merged.
- Cleanup waits for an idle Pi GUI and for `/cleanup` to settle before stopping processes.
- Adjusted spacing around the merge cleanup checkbox and explanation.
